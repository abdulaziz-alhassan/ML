In this project, I developed a complete machine learning workflow to predict loan repayment behavior using LendingClub data. The primary objective was to compare the performance of individual tree-based models against ensemble methods in a financial risk context.I performed in-depth EDA to uncover underlying patterns, specifically visualizing FICO score distributions and their correlation with interest rate trendsTo ensure compatibility with the Scikit-Learn library, I transformed categorical "purpose" data into numerical format using dummy variables. This step was critical as tree-based models require numerical inputs for splitting nodes.I first trained a single Decision Tree to establish a performance baseline.I then implemented a Random Forest classifier with 600 estimators, leveraging ensemble learning to reduce variance and improve prediction stability.I evaluated the models using Classification Reports and Confusion Matrices, leading to the following conclusions:
Overall Accuracy: The Random Forest model achieved a superior overall accuracy of 85%.
Class Sensitivity: Despite the lower overall accuracy of the single Decision Tree, it proved more effective at identifying high-risk borrowers.
Recall Trade-off: The Decision Tree exhibited higher recall for the minority class (likely defaulters), making it a potentially more valuable tool for risk-averse lenders who prioritize catching "bad" loans over maximizing total accuracy.
