For this project, I learned how to develop a machine learning workflow using Decision Tree and Random Forest models to predict loan repayment based on LendingClub data. I performed Exploratory Data Analysis (EDA) to visualize FICO score distributions and interest rate trends, and applied Feature Engineering using dummy variables to convert categorical "purpose" data into a numerical format. Because tree-based models require numerical input, this step was essential for compatibility with the Scikit-Learn library. I trained a single Decision Tree as a baseline and then optimized performance using a Random Forest with 600 estimators to provide a more robust ensemble prediction. Finally, I evaluated both models using Classification Reports and Confusion Matrices, concluding that while the Random Forest offered higher overall accuracy (85%), the Decision Tree was more effective at identifying risky borrowers due to its higher recall for the minority class.
